# Demo

Öffentliche Webseiten-Entwürfe von Tobias für Betriebe aus der Region (Rheintal).

- Jeder Entwurf liegt in einem eigenen Ordner und ist klar als Entwurf markiert.
- Alle Entwürfe sind für Suchmaschinen gesperrt (`robots.txt` und `noindex`).
- Keine Fotos oder Logos der Betriebe ohne deren Einverständnis.
- Die Startseite (`index.html`) ist Tobias' eigene Webseite und für Google sichtbar. Sie listet die Entwürfe bewusst nicht auf: Jeder Betrieb bekommt nur seinen eigenen Link.
- Schrift und Foto der Startseite liegen in `assets/`.

# Demo

Öffentliche Webseiten-Entwürfe von Tobias für Betriebe aus der Region (Rheintal).

- Jeder Entwurf liegt in einem eigenen Ordner und ist klar als Entwurf markiert.
- Alle Seiten sind für Suchmaschinen gesperrt (`robots.txt` und `noindex`).
- Keine Fotos oder Logos der Betriebe ohne deren Einverständnis.
- Die Startseite listet die Entwürfe bewusst nicht auf: Jeder Betrieb bekommt nur seinen eigenen Link.
